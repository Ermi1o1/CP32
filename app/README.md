# COP32 guide — native app (Phase 22)

Expo + React Native + TypeScript (D64). Android first; iOS later from the same code.
**Independent demonstration build — not an official COP32, UNFCCC or government app** (D65, D65a, D66).

This folder is separate from `prototype/` (the web prototype published by Netlify) and nothing here is published anywhere.

## Commands (run inside `app/`)
| Task | Command |
|---|---|
| Install | `npm install` |
| Type check | `npm run typecheck` |
| Unit tests | `npm test` |
| Regenerate the theme from the design tokens | `npm run tokens` |
| Web render (what the screenshots use) | `npm run export:web` |
| Run on a connected Android phone | `npx expo run:android` |
| Release APK | see `docs/operations/apk-build-runbook.md` |

## Where things are
| Path | What |
|---|---|
| `src/app/` | Screens, one file per route. `(tabs)/` holds the five primary tabs (D16 v2). |
| `src/ui/` | Base components. Screens use only these — never raw text or colours. |
| `src/theme/tokens.generated.ts` | **Generated** from `docs/design/tokens.json` by `docs/design/build_tokens.py`. Never edit by hand. |
| `src/theme/brand.ts` | The brand layer: name, mark, palette overrides. Two brands ship; swapping is configuration only. |
| `src/i18n/` | English and Amharic strings. Amharic is **not yet reviewed by a native-speaking editor**. |
| `src/data/` | Content model and the repository interface. Screens read content only through `ContentRepository`. |
| `src/state/prefs.ts` | Preferences, stored on the phone only. |
| `tests/` | Unit tests: contrast for every brand, language-file parity, script-aware fonts, data layer, preferences. |
| `assets/fonts/` | Atkinson Hyperlegible Next and Noto Sans Ethiopic, static weights, SIL Open Font Licence (copies included). |

## Rules that are easy to break
1. **No font, icon or image is fetched at run time.** Everything ships in the app (D49).
2. **Text containing Ge'ez goes through `src/ui/Text.tsx`**, which switches the whole string to Noto Sans Ethiopic. React Native does not fall back glyph by glyph, and some Android phones have no Ge'ez in their system font.
3. **No analytics, advertising or tracking packages** (D21). Check every new dependency.
4. **No calendar dates for COP32** until the host confirms them. Programme days are numbered (D66).
5. **No official marks.** No UNFCCC, official COP32 or Ethiopian-government logo or emblem, anywhere (D65).
6. The `android/` and `ios/` folders are generated by `npx expo prebuild` and are not committed.

## What has and has not been tested
See `docs/roadmap/phase-status.md`. In short: type checks, unit tests and browser renders run in the cloud session; **nothing has yet been run on a real phone.**

## Note for anyone (person or AI) changing this code
Expo changes its APIs with every release. This project is on Expo SDK 58 / React Native 0.88, where, for example, tabs are imported from `expo-router/js-tabs` and the stack from `expo-router/stack`. Check the versioned documentation (`https://docs.expo.dev/versions/v58.0.0/`) or the installed package's type definitions before using an Expo API from memory. Add packages with `npx expo install <name>` so versions match the SDK.
